Planar reflection bake - experimental v0.18.0

1. Restart Blender after installing. Choose Workbench 2.0 and Rendered viewport.
2. Set the scene camera to the view you intend to render.
3. Give the reflector an existing Principled material. For a sharp mirror,
   use Metallic 1 and Roughness 0. Roughness maps remain connected as normal.
4. In Edit Mode select only the front face, or a set of coplanar faces.
5. Open the viewport N sidebar > Workbench 2.0 > Planar Reflection Bake.
6. Click Bake / Rebake Planar Reflection. Wait for the Baked status.
7. Return to Object Mode. Bake again to reuse the configured face selection.
8. Clear Reflections removes this object's assignment. Unreferenced images
   created by this feature are removed; images shared elsewhere are retained.

One plane and camera-specific bake per object. Stored images are packed into
.blend files. Use the baked camera view for correct perspective. Rebake after
moving the camera, objects, or lights. Existing images remain until a new
capture succeeds. Shared materials and linked mesh data are not modified.

Current limits: opaque Principled/Diffuse surface graphs supported by the node
translator; apply/disable reflector modifiers before baking. Transparent
reflectors, recursive reflections, curved surfaces, live updates, and physically
accurate rough-reflection scattering are not implemented. Roughness uses a
finite image filter. Reflections on other objects are not included in captures.
No duplicate scene or vertex buffers; selected-face index buffers, cached
reflection shaders, a stored image, and temporary capture/shadow targets are used.

Validated: reflected-camera clipping, perspective/orthographic projection math,
shared-material/mesh isolation, GPU capture and shared-buffer identity, failure
state restoration, linked roughness texture effect, bake/rebake/clear operators,
image cleanup, packed image save/reopen, F12 with AO/shadows/outlines, and eight
unchanged existing scene regression images. This remains an early test build.
